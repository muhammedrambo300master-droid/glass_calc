## 💎 Why Glass_Calc?

Most stock Android calculators are plain, static, and uninspired. **Glass_Calc** brings the sleek **Apple-inspired liquid glass aesthetic** directly to Android without sacrificing performance or battery life.

* **🎨 Pure Visual Elegance:** Built using frosted-glass opacity, backdrop blur filters, and vibrant liquid animations that pop against pitch-black OLED displays.
* **⚡ Ultra Fast & Lightweight:** Compiled natively with Flutter to ensure 60+ FPS touch responsiveness and sub-10 MB memory footprint.
* **🔒 100% Offline & Private:** Zero tracking, zero telemetry, and **no internet permissions required**.
* **🧠 Scientific Powerhouse:** Switch seamlessly between standard arithmetic and advanced scientific operators with real-time live previewing.

---

## 🔥 Key Features

- 🧊 **Liquid Glassmorphism UI:** Translucent frosted-glass tiles with dynamic press responses.
- 🌑 **OLED Black Dark Mode:** Deep blacks paired with vivid accent highlights to save battery on modern screens.
- 🧮 **Scientific Functionality:** Dedicated trigonometric, logarithmic, root, and exponent functions.
- 📜 **Interactive History Log:** Swipeable drawer storing previous calculations with instant tap-to-reuse values.
- 📱 **Adaptive Edge-to-Edge Layout:** Native support for modern gesture navigation and dynamic display cutouts.

## 🛠️ Tech Stack & Packages

- **Framework:** [Flutter](https://flutter.dev/) (Dart)
- **UI Styling:** `glassmorphism` (Frosted Glass Containers & Blur Filters)
- **Utilities:** `url_launcher` (External Links & GitHub Routing)
- **Icon Generator:** `flutter_launcher_icons`
- **Minimum Target:** Android 6.0 (API Level 23)
- **Target SDK:** Android 14 / 15+ (API Level 36)
